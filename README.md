# AI Regression Testing Starter Kit — Free Edition

A practical starter kit for QA Engineers and SDETs testing AI/LLM applications.

## What's included

- 10 realistic AI regression scenarios
- CSV evaluation dataset
- Excel evaluation scorecard
- Python + pytest starter checks
- Promptfoo example configuration
- GitHub Actions CI workflow
- Quick-start guide
- Practical AI testing guide

## The workflow

Application → Evaluation Dataset → AI Evaluation → Regression Comparison → Report → Release Decision

## Free edition scope

This edition is intentionally small and practical. It is designed to help a QA engineer
understand and prototype an AI regression workflow. It does not bundle API keys or paid
model usage.

## Product positioning

This kit is a methodology and implementation starter, not an AI testing SaaS product.
It can be used alongside tools such as pytest and LLM evaluation platforms.
