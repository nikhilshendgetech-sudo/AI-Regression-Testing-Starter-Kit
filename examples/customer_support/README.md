# Customer Support AI Example

This example shows how common customer-support workflows can become repeatable AI regression tests.

## Workflow

1. Capture representative customer questions.
2. Provide approved knowledge/context.
3. Define expected behavior.
4. Run the same cases after prompt/model changes.
5. Compare results against the baseline.

## QA focus

- Correctness
- Relevance
- Scope adherence
- Unsupported claims
